# Contributing

Issues and pull requests are welcome. Keep changes focused on making the templates easier to use, edit, or compile.

## Before opening a pull request

- Keep shared layout and styling in `resume.cls`.
- Keep the new-grad template at one page and the experienced template at two pages.
- Use placeholder companies, roles, metrics, links, and contact details.
- Run `make` with XeLaTeX.
- Run `make preview` and review every page if the output changes.
- Run `git diff --check`.

In the pull request, explain what changed and why. Add before-and-after screenshots for visible layout changes.

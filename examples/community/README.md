# Community Resume Examples

This directory will hold reviewed, anonymized before-and-after bullet rewrites submitted by the people who wrote the originals. The maintainer-written [engineering bullet guide](../engineering-bullets.md) is separate.

## Reviewed index

No community examples yet. Accepted examples will be listed here by discipline and career stage.

## Submit an example

- No Git required: use the [resume example issue form](https://github.com/deepdave98/swe-resume-templates/issues/new?template=resume-example.yml).
- Pull request: copy [`TEMPLATE.md`](TEMPLATE.md) to `new-grad-backend-short-topic.md` or a similarly clear name. Submit one example per file.

GitHub issues are public. Redact the original before submitting it, and use placeholders such as `[COMPANY]`, `[PRODUCT]`, or `[TEAM]`. Do not post screenshots, dashboards, logs, customer data, or other private evidence.

Review checks that the rewrite preserves the author's real contribution and that any result is explained credibly. It does not certify employment or confidential measurements. If a number cannot be supported with a safe explanation of how it was measured, leave it out.

The submitter must own the original wording, have the right to share it, and permit publication under this repository's MIT License. Attribution is optional.
